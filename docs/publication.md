# Sanitized publication history

This repository is a separately initialized, allowlisted publication snapshot. It is not the original development repository or its complete commit history. The original private history and uncommitted work are preserved separately. Distinct public commits present the functional storefront baseline and the approved editorial redesign where practical.

Included: application source, generic schema/migrations, synthetic seed definitions, package/lockfile, local test source, original artwork, required public font licenses and sanitized product/architecture documentation.

Excluded: private environment/configuration, operator helpers, original Git metadata, personal machine paths, internal infrastructure routing, migration/support handoffs, raw QA logs/screenshots/traces, auth storage, external design archives, generated clients/builds, dependency directories and Vercel project linkage. GitHub publication does not configure or trigger a Vercel integration.

No credentials, hosted project identifiers, operational account details or actual customer data should be added. Review every future public diff and commit metadata before publication.
